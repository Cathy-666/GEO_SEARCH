# GEO AI Search 品牌效果检测 Demo

## AI自动监测品牌在AI平台中的曝光表现，支撑GEO效果验证

随着GEO（生成式引擎优化）进入规模化运营阶段，品牌需要持续了解：

- AI平台是否推荐自己的品牌？
- 品牌在回答中的出现位置如何？
- AI引用了哪些内容来源？
- 不同关键词下品牌表现如何？

传统GEO效果检测依赖人工逐个平台提问、记录和分析，随着关键词和AI平台增加，检测成本持续提升，难以支撑规模化运营。

本项目基于自动化能力，实现：

> **关键词输入 → AI回答采集 → 品牌识别 → 排名分析 → 效果看板**

帮助市场团队低成本完成AI搜索效果监测。

---


# 核心能力

## 1. 多AI平台回答自动采集

支持：

- 豆包
- DeepSeek
- 文心
- 元宝
- 千问

自动完成问题提交和回答获取。

---

## 2. 品牌曝光识别

自动分析AI回答中：

- 品牌是否出现；
- 出现频次；
- 品牌相关信息。

用于评估品牌在AI回答中的曝光情况。

---

## 3. 回答顺序分析

基于回答文本结构识别：

- 品牌出现顺序；
- 推荐位置；
- 品牌相对表现。

> 顺序结果基于文本识别规则，不代表平台官方评分或绝对排名。

---

## 4. 引用来源分析

识别AI回答中的相关引用信息，帮助分析：

- AI引用哪些内容来源；
- 哪些媒体/页面更容易被AI采纳。

---

## 5. 自动生成检测看板

输出：

- 单问题检测结果；
- 品牌曝光统计；
- 回答顺序分析；
- 引用信息汇总。

支持 XLSX / CSV 导出。

---

# 项目价值

本Demo展示GEO AI Workflow中的**效果检测与数据反馈环节**。

在实际业务场景中：

- 覆盖多个AI平台；
- 支撑400+关键词持续检测；
- 检测周期由人工月度回收缩短至周度反馈；
- 大幅降低人工重复执行成本。

通过自动化检测，将原本依赖人工经验的GEO效果验证，转化为可持续的数据反馈流程。

# 真实采集运行方式（Windows）

## 环境要求

- Node.js 20+
- Google Chrome

## 运行步骤

1. 双击：
start_demo.bat

2. 输入需要检测的品牌名称。

3. 首次运行联网安装依赖。

4. 在调试 Chrome 中登录AI平台。

5. 运行检测任务。

6. 完成后自动生成检测看板。

> 部分平台可能因登录状态、访问限制、页面变化等原因出现采集失败。

---

# 数据分析说明

## 出现率

当前规则判定出现的成功回答数 / 成功回答数。

异常回答不计入分母。

---

## 顺序位次

按照回答文本中的：

- 章节；
- 表格行序；
- 正文顺序；

识别品牌出现位置。

仅计算词表内品牌，不代表平台评分或完整推荐列表中的绝对排名。

---

## 平均位次

仅统计能够识别顺序的有效回答。

跨行业使用时，需要根据行业调整品牌词表和问题库。

---

## 引用说明

- 引用分析基于AI回答中展示的信息；
- 不访问引用文章正文；
- 未展示引用不代表平台不存在引用。
