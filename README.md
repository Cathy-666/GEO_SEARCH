# AI Search 品牌自动检测｜参赛演示版

面向全行业的品牌 AI 搜索监测工具：将问题清单发送到五个 AI 平台，汇总品牌出现情况、回答顺序及相关引用，减少重复检索和整理表格。

## 先看效果

- GitHub：https://github.com/Cathy-666/GEO_SEARCH
- [示例看板](examples/dashboard.html)：下载后双击打开，无需安装或登录。GitHub 页面显示源码，请下载后查看。
- 示例全部为合成数据，不代表真实平台输出或实际业务收益。

## 功能

豆包、DeepSeek、文心、元宝、千问网页采集 → 品牌识别 → 本地看板 → XLSX/CSV 导出。支持逐题结果、媒体筛选、问题搜索及异常状态。

## 真实采集（Windows）

1. 安装 Node.js 20 或更新版本和 Google Chrome。
2. 双击 start_demo.bat，输入品牌名，首次运行联网安装依赖。
3. 在调试 Chrome 中登录五个平台。
4. 首次建议输入题号 1-3；回车运行全部问题。耗时取决于响应和重试。
5. 完成后看板自动打开；部分失败会显示提示，不算全部成功。

手动检查：npm ci，然后 npm test。已有数据可用 rebuild.ps1 重建，支持 YYYYMMDD 日期。
失败平台默认对所选问题整体重试一次，--noretry 关闭重试；同平台同问题展示最新批次。

## 统计口径

- 出现率：当前规则判定出现的成功回答数 / 成功回答数，异常回答不计入分母。
- 顺序位次：按章节、表格行序和正文顺序识别、去重，仅计算词表内教育品牌及当前品牌；不是平台评分、市场排名或完整列表中的绝对名次。
- 平均位次：仅计入识别出位次的回答；跨行业使用需调整词表和问题。
- 内置品牌使用词表别名；自定义品牌按输入名称匹配。引用标题仅按完整品牌名称过滤，不扩展别名。
- 引用模块不访问文章正文；没有展示不等于平台没有引用。
- 登录、限频、网络和网页结构变化均可能造成采集失败。本版尚未完成五平台真实采集验收。

## 目录

- run_v3_fixed.js：采集及逐题保存。
- brand_ranking.js：教育品牌词表和顺序检测。
- build_dashboard.js：统计、看板与导出。
- questions/master.csv：教育行业示例问题。
- examples/：合成数据、看板及生成脚本。
- data/、chrome_cdp/、demo-config.json：本地运行数据，已排除上传。
